# Release checklist

## Completed for this delivery

- [x] Native Xcode project, pinned bundled model, no required service credentials.
- [x] Original concept, harbor, mascot and icon; prompts and editable originals retained.
- [x] Three connected journeys implemented with persistent local data.
- [x] Real on-device analysis, manual confirmation, unknown and unsuitable-photo paths.
- [x] Reviewed NYC access/species sources, dates and changing-rule links.
- [x] Privacy notices, stripped photo GPS, coarse/withheld catch areas, export and deletion.
- [x] Core, UI, location and metadata checks; known native audit false positive documented.
- [x] Actual simulator screenshots and an automated recording; measured limitations retained.
- [x] Live foreground motion review and replacement showcase video accepted on the unlocked Studio, September 6, 2026.
- [x] Clean-clone Release build, MIT license and third-party notices.
- [x] Code and delivery materials committed and pushed to the GitHub source of truth.

## Required before broad release or stronger claims

- [ ] Install on an available signed physical iPhone; verify real camera permission,
      capture/import cancellation, background/foreground recovery and low-memory behavior.
- [ ] Test spoken VoiceOver focus/order, felt haptics, Reduce Motion settings,
      small-screen/landscape use and touch ergonomics on hardware.
- [ ] Profile rendered scrolling, map interactions and the heaviest photo/journal view
      with device Instruments; establish sustained frame times/lows/hitches and thermal
      behavior. No 60 fps claim is currently supported.
- [ ] Run a broader, independently labelled fish dataset with lookalikes, juveniles,
      out-of-set species, lures and multiple fish. Establish useful operating thresholds
      or replace the general model before marketing reliable identification.
- [ ] Verify genuine offline/airplane-mode behavior on the device, unavailable external
      resources, large exports and device file-protection recovery.
- [ ] Exercise the minimum supported OS and iPad layout if retaining universal-device
      distribution. Only the declared iPhone simulator runtime was executed here.
- [ ] Recheck regulations/access immediately before release and verify NY Health's
      advisory link through a normal browser. No stale limits are embedded in the app.
- [ ] Review the final privacy manifest/store privacy answers and signing entitlements.
      App Store Connect submission, TestFlight and review have not been performed.

These remaining gates are explicit evidence boundaries. The delivery does not
silently mark unavailable physical-device or accuracy/performance work passed.
